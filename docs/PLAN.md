# 猎场系统 V6.0 "Genesis" — 小资金 AI 量化交易系统

## Context

基于猎场系统 V5.2 蓝图 + GitHub 开源框架调研，为 **2万元小资金** 重新设计的 AI 原生量化交易系统。

### 核心约束与设计原则

| 约束 | 设计决策 |
|------|----------|
| **资金 200万** | 最大持仓 6 只，单票仓位 ≤25%（约50万/只） |
| **市值范围** | 10-50亿（≤50亿小盘股，聚焦15-35亿甜点区） |
| **股价范围** | 3-80 元 |
| **市场** | A股（主板+创业板）+ 可转债（T+0，免印花税）+ 港股（港股通预留） |
| **手续费敏感度** | 中低（单笔最低佣金5元，对200万影响较小） |
| **风格** | 小市值（≤50亿）+ 止跌企稳 + 追涨突破 |
| **数据源** | Tushare Pro（主）+ AkShare（免费备选）+ 腾讯 WebSocket（实时） |
| **界面** | Windows 系统托盘 + Web 面板（FastAPI + ECharts） |
| **LLM** | 本地 Ollama + Qwen2.5-7B（离线推理）+ DeepSeek API 云端备选 |
| **打包** | PyInstaller → EXE + NSIS 安装器 + Windows Service |

### 借鉴的 GitHub 开源框架

| 框架 | Stars | 借鉴内容 |
|------|-------|----------|
| [Qbot](https://github.com/UFund-Me/Qbot) | 18k+ | AI/RL 决策引擎、多模型信号融合、因子自动挖掘、全链路闭环 |

## 三、核心模块详解

### 3.1 数据接入层

| 数据源 | 类型 | 覆盖 | 频率 | 用途 |
|--------|------|------|------|------|
| Tushare Pro | REST API | A股日K/市值/财务 | 盘中每20分钟 | 主数据源 |
| AkShare | REST API | A股+港股+可转债 | 每30分钟 | 免费备选 |
| 腾讯行情 | WebSocket | 实时价/换手率/量比 | 实时推送 | 盘中决策 |
| 东财新闻 | REST + NLP | 利空/利好分类 | 每5分钟 | 信号过滤 |
| 新浪财经 | REST | 港股实时行情 | 每10秒 | 港股监控 |

### 3.2 AI 决策引擎（借鉴 Qbot 多模型架构）

```
决策流程:
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 行情哨兵全市场扫描（每20分钟，5000+股票 → Top 50）   │
│ Step 2: 特征提取（每只候选股 → 128维向量）                   │
│ Step 3: XGBoost 评分  + LSTM 预测  + CatBoost 风险分类      │
│ Step 4: 信号验证（继承 V5.2 十层防线）                       │
│ Step 5: PPO 仓位优化（给定信号+当前持仓 → 最优仓位比例）     │
│ Step 6: LLM 宏观确认（极端行情预警，非必过）                  │
│ Step 7: 输出决策 → 人工确认 → 下单                           │
└─────────────────────────────────────────────────────────────┘
```

**关键差异（vs V5.2）：**
- V5.2: 固定规则评分 → V6.0: XGBoost 动态评分（每周重训练）
- V5.2: 三等分固定仓位 → V6.0: PPO 动态仓位（市场好时重仓，差时轻仓）
- V5.2: DeepSeek 仅出报告 → V6.0: LLM 参与极端行情判断
- V5.2: 无预测能力 → V6.0: LSTM 1/3/5日涨跌预测

### 3.3 五层风控（继承 V5.2 十层 + 适配2万资金）

```
V5.2 十层防线（保留并增强）:
  L1 市值过滤: 20-100亿 (V5.2: 30-100亿，放宽适应小资金)
  L2 数据完整性: RSI/换手率/量比/回撤 任一缺失 → 拒绝
  L3 假数据检测: RSI=50 AND 换手率=0 AND 量比=1.0 → 拒绝
  L4 涨停过滤: 涨幅>9% OR 涨停封板 → 拒绝
  L5 评分过滤: AI评分<40分 → 拒绝 (V5.2: 45分)
  L6 宏观情绪: 恐贪指数<20(极度恐惧) OR >80(极度贪婪) → 警告
  L7 新闻研判: NLP判定利空 → 拒绝
  L8 基本面黑名单: 减持/立案/亏损/ST → 拒绝
  L9 缩量止跌: 换手率>10%放量下跌 → 拒绝
  L10 底部横盘: 3日内创新低 → 拒绝

新增 AI 防线:
  L11 CatBoost 风险: 模型预测5日跌>5%概率>60% → 拒绝
  L12 流动性检查: 日均成交额<2000万 → 拒绝（小资金也要能卖出）

五层递进熔断（新增，V5.2仅有L1止损）:
  L1 个股止损: -5% → 立即平仓
  L2 个股日损: -3% → 次日禁止该股
  L3 组合日损: -4% (~800元) → 禁止新开仓
  L4 组合周损: -8% (~1600元) → 全平+本周停止
  L5 大盘熔断: 沪深300跌>5% → 清仓+暂停
```

### 3.4 仓位管理（专门为2万设计）

```
资金: 20,000元
策略: Kelly公式 + 波动率调整 + 小资金约束

投资标的优先级:
  1. 可转债 (T+0, 无印花税, 1手=10张≈1000-3000元, 流动性好)
     → 配置 30-50% 资金
  2. A股小市值 (20-100亿, 股价3-30元, 1手=300-3000元)
     → 配置 50-70% 资金
  3. 港股小票 (港股通, 股价1-30港元, 注意每手股数不同)
     → 配置 0-30% 资金（视港股通额度）

单票仓位约束:
  - 最大单票仓位: 70% (~14,000元)
  - 最大持仓数: 2只
  - 现金保留: ≥20%（应对机会/T+1结算）

可转债专项:
  - T+0交易, 当日可买卖多次
  - 无印花税(省0.05%)
  - 优先选择: 双低转债(低价+低溢价率)
  - 止损: -3%（流动性好可更紧）
```

### 3.5 自进化闭环

```
每日（全自动）:
  15:30  收盘数据同步
  15:45  绩效归因（每笔交易 → 信号源 → 盈亏归因）
  16:00  AI 复盘报告（LLM 分析今日得失 + 明日预判）
  16:15  信号回溯（今日所有信号 vs 实际走势 → 命中率更新）
  16:30  更新策略生命周期数据

每周六（全自动）:
  09:00  周度绩效汇总（收益率/夏普/胜率/最大回撤）
  10:00  遗传算法超参优化（种群50, 迭代30代）
        - 优化目标: 夏普比率 × 胜率
        - 优化参数: 信号阈值, 仓位系数, 止损比例
  11:00  模型增量训练（加入本周新数据）
  12:00  A/B 评估（模拟盘新策略 vs 实盘策略）

策略淘汰规则:
  - 连续 3周 夏普<0 OR 收益<0 → 标记"观察"
  - 连续 4周 观察 → 自动降级为"模拟"
  - 连续 4周 模拟盘夏普>0.5 → 可晋升实盘

安全约束:
  - 参数单次调整 ≤20%
  - 新策略须模拟盘≥2周验证
  - 所有变更自动记录 changelog
```

## 六、关键性能指标

| 指标 | 目标 |
|------|------|
| 全市场扫描 | <30秒（5000+股票 → Top 50） |
| AI 推理延迟 | <500ms（4模型集成推理） |
| WebSocket 延迟 | <200ms |
| 回测速度 | >1000只/分钟（日K级别） |
| 内存占用 | <4GB（含 LLM） |
| EXE 体积 | <3GB（含 Ollama + 模型） |
| 轻量 EXE（无LLM） | <500MB |

## 七、验证方案

1. **回测验证**: 2022-2025 年数据回测，对比买入持有基准
2. **模拟交易**: 实时行情模拟 ≥4 周，验证决策质量
3. **风控测试**: 五层熔断逐层触发测试
4. **极端行情**: 测试 2024-02 量化危机、2020-02 疫情暴跌场景
5. **手续费验证**: 确认每笔交易手续费计算正确（对2万资金至关重要）

## 八、与 V5.2 关键差异总结

| 维度 | V5.2 | V6.0 |
|------|------|------|
| 资金量 | 360万（三队各120万） | 2万（单账户） |
| 持仓数 | 8只（三队） | 1-2只 |
| 决策方式 | 固定规则评分 | XGBoost + LSTM + PPO 集成 |
| 仓位管理 | 三等分固定 | Kelly + 波动率动态调整 |
| 风控层级 | 1层止损 | 5层递进熔断 |
| 数据推送 | crontab轮询 | WebSocket实时 + 事件驱动 |
| AI 角色 | 辅助出报告 | 核心决策 + 自主进化 |
| 交易品种 | 仅A股 | A股 + 可转债 + 港股 |
| 平台 | Mac crontab | Windows EXE + Service |
| LLM | DeepSeek API | 本地 Qwen2.5 + DeepSeek备选 |
